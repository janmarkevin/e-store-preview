# Kevin Store Preview

Standalone static frontend prototype for client demos. Isolated from the Laravel + Inertia production app.

## Stack

- React 19 + TypeScript + Vite
- React Router
- Tailwind CSS 3.4 + SCSS (BEM semantic classes in TSX)
- Local mock data only

## Commands

```bash
cd kevin-store-preview
npm install
npm run dev
npm run build
npm run preview
```

## Vercel

- Root directory: `kevin-store-preview`
- Build: `npm run build`
- Output: `dist`
- SPA rewrites: see `vercel.json`
